# bibliamulher-legal

Páginas legais do app **Bíblia da Mulher** (Hermes Digital), publicadas por GitHub Pages
em https://hermesdigitalbr-spec.github.io/bibliamulher-legal/

- `/terms`, `/privacy`, `/support` (pt-BR; o app é só em português).
- O app aponta para `/terms.html` e `/privacy.html` — não renomear os arquivos.
- Para editar: altere o texto em `build.py` e rode `python3 build.py` (gera os `.html` com o CSS embutido).
